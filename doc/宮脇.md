# プロジェクト構成ドキュメント：レーシングゲーム・データ連携システム

## 1. 概要
本プロジェクトは、Unityを用いた2Dレーシングゲームであり、レースの「走行計測」「結果の永続化（JSON）」「IDベースのリザルト表示」「動的なBGM演出」を統合したシステム。

---

## 2. シーン構成と画面遷移
プロジェクトは以下の3つの主要シーンで構成され、静的クラス `GameResultData.cs` をポインタとして利用して遷移する。

- **StartScene**: コース選択およびゲーム開始待機。
- **RaceScene**: 走行、チェックポイント通過、ゴール判定、制限時間管理。
- **ResultScene**: 走行結果の表示、ランキングの動的生成、背景の自動切り替え。

---

## 3. ファイル構成と役割

### A. システム・データ管理
| ファイル名 | 役割 |
| :--- | :--- |
| `Types.cs` | `RankingEntry` 等のデータ構造定義および `TimeFormatter` (時間整形) の提供。 |
| `RankingManager.cs` | `ranking.json` への読み書き、ソート、トップ5抽出のロジック。 |
| `GameResultData.cs` | シーン間を跨ぐID (`LastEntryId`) の保持と遷移先名の定義。 |

### B. スタートシーン (StartScene)
| ファイル名 | 役割 |
| :--- | :--- |
| `MenuController.cs` | キーボード入力（1,2,3）によるコース選択と、BGM・テキストの制御。 |
| `BGMManager.cs` | イントロからループへの遷移、およびコース確定時のトラック切り替え（クロスフェード/即時）。 |

### C. レースシーン (RaceScene)
| ファイル名 | 役割 |
| :--- | :--- |
| `LapCounter.cs` | チェックポイント・周回判定、ゴール時のデータ保存、IDの発行。 |
| `countdown.cs` | カウントダウン演出、制限時間（タイムアップ）管理、BGM再生トリガー。 |
| `GameBGMManager.cs` | レース開始時のBGM再生、および終了時のフェードアウト処理。 |
| `CircuitLoader.cs` | コースデータの読み込み、コース名の提供。 |

### D. リザルトシーン (ResultScene)
| ファイル名 | 役割 |
| :--- | :--- |
| `ResultScreenController.cs` | IDを元にしたデータ逆引き、順位計算、UI Toolkitへの描画。 |

---

## 4. 主要なデータフロー
1. **保存**: `LapCounter.cs` または `countdown.cs` が、ユニークIDを生成して `RankingManager.cs` 経由で `ranking.json` に保存。
2. **橋渡し**: 生成したIDのみを `GameResultData.LastEntryId` にセットしてシーン遷移。
3. **参照**: `ResultScreenController.cs` がIDをキーにしてJSONから全データを読み出し、該当マップのランキングにおける順位を計算して表示。

---

## 5. BGMシステム設計
- **同期再生**: `AudioSettings.dspTime` を利用し、複数トラック（Normal/Heavy）を無音状態で同時に再生開始し、同期を維持。
- **動的制御**: 
    - メニュー：コース確定時にドラムトラックをオン。
    - レース：ゴール/タイムアップ時にコルーチンによるボリュームフェードアウト。
